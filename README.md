# Connect The Skybrisk

Static React + Vite website for connect-theskybrisk.com.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown by Vite, usually http://localhost:5173.

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

Import this project into Vercel. The included `vercel.json` keeps React Router routes working on refresh.

## Important

Update any organization/contact/legal details in the React components before production if your current official information changes.
